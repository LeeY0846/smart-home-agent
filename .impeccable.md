## Design Context

### Users
Personal project / portfolio piece — built by a developer for themselves, to showcase AI-powered smart home control with a distinctive aesthetic. No non-technical end-users. The audience viewing this is other developers and people who appreciate crafted, opinionated interfaces.

### Brand Personality
**Playful · Nostalgic · Crafted**

The tone is retro gaming — like booting up a SNES game. Every interaction should feel tactile and deliberate. The interface is a technical demo that doubles as an art piece: it should make someone stop and say "that's cool" before they even read a word.

### Aesthetic Direction
**Retro arcade / pixel art game** — lean hard into 8-bit and 16-bit game UI conventions:
- Press Start 2P as the primary typeface throughout
- Dark navy background (#0d0d1a range) as the canvas
- Limited, intentional color palette: amber for lights, blue-cyan for AC, green/red for status
- Hard pixel shadows (no blur), no border-radius anywhere
- Scanline CRT overlay on the house panel
- Device state changes should feel like game events — immediate, satisfying

**Anti-references (explicitly avoid):**
- Generic smart home apps (iOS HomeKit whiteness, Google Home cards)
- Corporate SaaS dashboards (metric cards, chart grids, data tables)
- Heavy glassmorphism (frosted blur cards on gradients)
- AI chatbot look (plain centered white conversation thread)

### Design Principles
1. **Pixel-perfect consistency** — every element in the pixel art interface uses the pixel design system exclusively. No mixing of the app's light-mode nature palette (sea-ink/lagoon/palm) with the game UI.
2. **Game UI conventions** — borrow from real game interfaces: status bars, item cards, terminal-style chat, room maps. If it could appear in a 16-bit RPG inventory screen, it belongs here.
3. **State = visual event** — every device state change must register visually (glow, color shift, icon change). The house should feel alive and reactive, not static.
4. **Typography discipline** — Press Start 2P at controlled sizes (5px–8px for labels, never larger than 10px for body). Its extreme width demands restraint. Never use it for long text.
5. **No safe defaults** — this is a portfolio piece. It should be memorable and opinionated. Avoid anything that looks like it came from a template or a UI library.
